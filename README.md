# מרחב · אימון חשיבה מרחבית

אימון אישי למבחני התאמה בתחום המרחבי: רוטציה מנטלית וקיפול ופריסה, בדו-ממד ובתלת-ממד, סטטי ודינמי, עם מסלול רמות, משוב לכל טעות ואבחון.

- אפיון: [docs/SPEC.md](docs/SPEC.md)
- הנחיות פיתוח: [CLAUDE.md](CLAUDE.md)

## הפעלה
```
npm install
npm run dev
npm test
```

## פריסה
Vercel (Vite). `vercel.json` מגדיר rewrite ל-SPA. אפשר לעקוף את כתובת Supabase ואת המפתח הציבורי במשתני `VITE_SUPABASE_URL` ו-`VITE_SUPABASE_PUBLISHABLE_KEY`.

## נתונים
מקומית ב-localStorage, ובענן ב-Supabase (פרויקט cultura-GH, טבלאות `visual_*`), דרך פונקציות RPC בלבד, לפי קוד סנכרון. אין הרשמה.

## מקורות
סוגי המבחן מבוססים על חומרי הכנה ציבוריים, לא על מבחן של מכון מסוים. נתונים מספריים ממחקרים לא הוכנסו לפני אימות.
